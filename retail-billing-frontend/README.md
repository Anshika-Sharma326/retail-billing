# Retail Billing Portal

A professional retail billing management system built using React and Vite.

## Features

- User Login Authentication
- Dashboard with sales overview
- Product Management
- Customer Management
- Billing System
- Invoice Generation
- Sales Reports
- Local Storage Data Management
- Responsive UI Design

## Technologies Used

- React.js
- Vite
- Material UI (MUI)
- JavaScript
- HTML5
- CSS3
